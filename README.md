# Voxel Atelier

一个受经典体素沙盒启发的原创浏览器游戏。它不包含 Minecraft 的官方代码、纹理、音效或品牌素材。

## 当前可玩内容

- 程序化草地、泥土、石头、树木、树叶、沙地与水面
- 动态昼夜、天空雾效、定向阳光和飘动云层
- 第一人称鼠标视角、WASD/方向键移动、跳跃与简单地形碰撞
- 左键挖掘、右键放置、射线选中与 1–6 / 滚轮快捷栏
- 自动本地保存，以及“生成新世界”重置入口

## 本地启动

```bash
npm install
npm run dev
```

浏览器中点击“进入世界”锁定鼠标。按 `Esc` 可退出并打开菜单。

## 质量检查

```bash
npm test
npm run build
```
