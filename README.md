# Voxel Atelier

一个受经典体素沙盒启发的原创浏览器游戏。它不包含 Minecraft 的官方代码、纹理、音效或品牌素材。

## 当前可玩内容

- 程序化草地、泥土、石头、树木、树叶、沙地与水面；可辨识平原 / 沙漠 / 海洋群系
- 无限开放世界：区块流式生成，围绕玩家持续扩展；初始半径保留以兼容存档
- 动态昼夜、星空与月亮、天空雾效、定向阳光和飘动云层
- 随源码生成的原创 16px 像素材质（不依赖任何官方纹理文件）
- 渲染时自动剔除完全被包围的地底方块，减少无效绘制
- 第一人称鼠标视角、WASD/方向键移动、跳跃与简单地形碰撞
- 左键长按挖掘、右键放置（持方块优先于拉杆交互）、1–9 / 滚轮热键栏（色块+中文短标可辨识）
- 新世界赠送基础方块，避免「右键放不出」；空槽会提示而非静默失败
- 从零采集方块；按 `C` 将 1 原木合成为 4 木板
- 自动本地保存（世界、位置、快捷栏和背包），以及“生成新世界”重置入口
- 原生同源联机房间：两名玩家输入同一房间码后可同步移动、方块放置/破坏与入房世界快照；刷新后可用同一码重连
- 确定性平原村庄：房屋、道路与砖砌广场会随种子生成；左上角显示坐标，按 `P` 可再次查看，房屋门口锚点可供后续村民系统使用

## 本地启动

```bash
npm install
npm run dev
```

浏览器中点击“进入世界”锁定鼠标。按 `Esc` 可退出并打开菜单。

## 双人联机试玩

1. 执行 `npm run dev -- --host 127.0.0.1`，在同一个浏览器打开显示的地址和第二个标签页。
2. 两个标签页在开始菜单输入相同的房间码（例如 `forest-42`），点击“创建 / 加入房间”。
3. 分别进入世界；左上角会显示房间名与人数。移动一名玩家或放置/破坏方块，另一标签页应立即看到同步结果。

联机 MVP 使用浏览器原生 `BroadcastChannel`，并在其不可用时回退到 `localStorage` 事件，因此当前适用于同一网站来源下的双标签页联调。跨设备公网房间与服务端权威同步属于后续联机增强阶段。

## 图标 / 贴图素材管线（数据收集）

可重复的 wiki 采集脚本在 `tools/icon-scrape/`（见该目录 README）。产物在 `assets/icons/`：结构化清单、`itemId→纹理` 映射，以及按许可隔离的本地缓存（`distributable` / `restricted` / `unknown`）。当前缓存为 wiki 可引用图，标记为受限参考素材，**不作为可分发官方贴图入库**。

前端通过 `src/icons.ts` 读取 `mapping.json`：热键栏与准星下手持预览使用可辨识图标；世界方块面在预览构建中加载同一缓存（仍落在 `cache/restricted/`，不迁入 `cache/distributable/`）。正式对外分发需待许可清理后再切 atlas。
